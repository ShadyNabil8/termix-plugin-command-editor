# Changelog

## 1.0.0

### Added

- Edit the command at the prompt in a floating editor over any SSH terminal
- Open it with Ctrl+Shift+X, the terminal toolbar, the command palette or a key of your own
- Insert the edited command back at the prompt, or run it
- Multi-line commands go in as one paste
- Settings for the key, how the line is cleared, font size and line wrapping
- Uses the prompt access of newer SSH Terminal versions: the local terminal, the exact cursor line, no opening inside full-screen programs, and a warning when a shell would run a multi-line paste line by line
